# Ironlog APK

[`ironlog.apk`](ironlog.apk) is always the newest build of the app. After every change to `main`, GitHub Actions builds the app and runs every test and lint check. If they pass, it replaces this file automatically.

**Install on Android 8.0 or newer:**

1. Open [`ironlog.apk`](ironlog.apk) on your phone and tap **Download raw file**.
2. Open the downloaded file and allow installs from that app when Android asks.
